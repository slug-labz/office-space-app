How full the plan is

What Claude Code reports about this plan’s allowance — a bucket that empties and refills. It is measured on the first event of a run, so the newest reading available is always the last run’s.

What runs on a hook

Hooks are Claude Code’s own. A hook is a command a settings file registers against an event — it runs for every session in this workspace, including a plain terminal claude that has never heard of this app. A file in .claude/hooks/ that nothing registers never runs.

Services the office can reach

Connectors are Claude Code’s own. Adding one here writes it into .mcp.json — it is not a login, nothing is started, and Claude Code asks you to approve a new server the first time it sees one.
