# Themes — your own art goes here

Office Space draws its people in code. That theme ships, works offline on a fresh clone, needs
no purchase, and renders an unlimited cast. It is the default and it is not a fallback.

If you would rather use a commercial pixel-art pack you have bought, it goes in this directory:

```
assets/themes/<your-theme-id>/
  theme.json
  <sheet>.png
```

**And it stays here.** Every commercial pack we reviewed permits commercial use and forbids
redistribution, so `assets/themes/**` is gitignored apart from this file. Committing a pack you
paid for would breach the licence you paid for.

Full instructions, a worked `theme.json`, and the licence reasoning: [docs/themes.md](../../docs/themes.md).
